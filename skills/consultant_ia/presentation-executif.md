# Skill — Présentation C-level & Comité de Direction
> Certifications : PROSCI · CAP IABAC

## Objectif
Préparer et délivrer des présentations percutantes pour les décideurs : DG, DSI, CDO, CODIR.

## Règles d'or pour une présentation C-level
1. **1 slide = 1 idée** — pas de surcharge
2. **Commencer par la conclusion** — les dirigeants n'ont pas le temps d'attendre
3. **Quantifier tout** — "30% de réduction des coûts" > "amélioration significative"
4. **Anticiper les 3 questions** qu'ils poseront forcément
5. **Demander une décision** — chaque présentation doit se terminer par un "Que validez-vous ?"

## Structure Pyramid (McKinsey)
```
Situation   → Contexte actuel (1 slide)
Complication → Problème ou opportunité (1 slide)
Résolution  → Notre recommandation (1 slide)
Arguments   → Preuves et détails (3-5 slides)
Call to action → Décision demandée (1 slide)
```

## Template CODIR IA (10 slides max)
```
1. Titre + date + participants
2. Synthèse exécutive (3 bullets : contexte, recommandation, ROI)
3. Contexte : pourquoi l'IA maintenant ?
4. État des lieux : où en sommes-nous ?
5. Les 3 opportunités prioritaires
6. Notre recommandation (option choisie + pourquoi)
7. Feuille de route macro (18 mois)
8. Investissement et ROI attendu
9. Risques et mitigation
10. Décision demandée + prochaines étapes
```

## Adapter au profil du décideur
| Profil | Langage | Focus | Peur |
|---|---|---|---|
| **DG** | Business, impact | ROI, avantage concurrentiel | Risque image |
| **DSI** | Technique, intégration | Architecture, sécurité | Dette technique |
| **CDO** | Data, IA | Maturité, gouvernance | Qualité données |
| **DRH** | People, change | Adoption, formation | Résistance équipes |
| **DAF** | Coûts, ROI | TCO, business case | Dépassement budget |

## Livrables
- Deck PowerPoint / Google Slides (10 slides max)
- Notes de présentation (1 page par slide)
- One-pager synthèse (pour les absents)
- Q&A anticipé (10 questions / réponses)

## Format de sortie
Précise : public cible (DG, DSI, CODIR) · sujet · durée allouée · décision attendue · niveau de formalisme
