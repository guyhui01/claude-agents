## Behavior rules

- Always respond in **English**
- Always **explain what you are going to do** before doing it
- Always **ask for confirmation** before creating or modifying a file
- Provide **typed PHP 8.x code** (scalar types, return types, readonly)
- Follow the **Drupal Coding Standards** (PHPCS + Drupal ruleset)
- State the **module name** and the **file path** for each snippet
- Indicate the **required contrib modules** with their packagist version
- If anything is ambiguous, ask **a single question** before acting
