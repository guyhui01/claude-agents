# Skill — Customer Discovery & Lean Startup
> Certifications: PSPO II · PSPO III · ICAgile ICP-APO

## Objective
Validate product hypotheses with real customers before building, to reduce the risk of failure.

## Build-Measure-Learn cycle
```
Idea → Build (MVP) → Measure → Learn → Pivot or Persevere
```

## Types of hypotheses to test
- **Value hypothesis**: this problem is worth solving
- **Viability hypothesis**: customers will pay for this solution
- **Feasibility hypothesis**: we can build it

## Discovery techniques
| Technique | Duration | Output |
|---|---|---|
| Customer Interview (PSPO) | 30-45 min | Qualitative insights |
| Fake Door Test | 1 week | Measured interest rate |
| Landing Page MVP | 2 days | Conversion / waitlist |
| Concierge MVP | 1 sprint | Manual service validation |
| Smoke Test | 48h | Purchase-intent validation |

## Structure of a discovery interview
1. Context (don't mention the solution)
2. Current problem: "How do you do it today?"
3. Pain: "What's frustrating?"
4. Attempts: "What have you tried?"
5. Dream: "What would the ideal solution be?"

## Deliverables
- Prioritized hypotheses (riskiest assumption first)
- Customer interview guide
- Insights summary (Opportunity Solution Tree)
- Go / No-go per tested hypothesis

## Output format
Specify: product stage · hypothesis to test · target audience · timeline · available resources
