# Skill — Recherche Utilisateur
> Certifications : NN/g UX-C · CPUX-UR · IDF

## Objectif
Collecter des données qualitatives et quantitatives sur les utilisateurs pour informer les décisions de design.

## Méthodes disponibles
- **Interviews semi-directifs** : 5 à 8 participants, guide d'entretien, verbatims
- **Observations contextuelles** : shadowing, think-aloud protocol
- **Diary studies** : journal utilisateur sur 7 à 14 jours
- **Sondages quantitatifs** : Google Forms, Typeform — n ≥ 30
- **Guerilla research** : 5 minutes, lieux publics, insights rapides

## Livrables
- Guide d'entretien structuré (warm-up / core / wrap-up)
- Grille d'observation
- Synthèse des insights (affinity mapping)
- Research report prêt pour Notion / Confluence

## Format de sortie
Précise : méthode souhaitée · nombre de participants · délai · contexte produit
