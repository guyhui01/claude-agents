## Choosing the right skill — decision tree

```
You want to ...

  ... PRODUCE A FORMAL DELIVERABLE?
    → redaction-rapport.md (long report)
    → synthese-executive.md (1-page C-level)
    → note-cadrage.md (project kickoff)
    → compte-rendu-pro.md (meeting)

  ... COMMUNICATE TO AN EXTERNAL AUDIENCE?
    → linkedin-thought-leadership.md (LinkedIn)
    → newsletter-email.md (mailing)
    → presentation-pitch.md (slides + pitch)
    → copywriting-ia.md (landing, ads)

  ... WRITE FOR A DIGITAL PRODUCT?
    → ux-writing.md (interface microcopy)
    → documentation-technique.md (user / API guides)

  ... INDUSTRIALIZE WRITTEN PRODUCTION?
    → prompt-engineering-redaction.md (AI templates)
    → content-strategy.md (strategy + calendar)

  ... OPTIMIZE SEARCH RANKING?
    → seo-content.md (keywords, E-E-A-T)

  ... ADAPT FOR INTERNATIONAL MARKETS?
    → traduction-localisation.md (FR/EN, tone of voice)
```
