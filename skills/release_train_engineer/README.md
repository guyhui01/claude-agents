## Choosing the right skill — Decision tree

```
You want to ...

  ... PREPARE A PI PLANNING?
    → facilitation-pi-planning.md (agenda + Program Board + PI Objectives)

  ... COORDINATE THE TEAMS DAY TO DAY?
    → coordination-art.md (roles + cadence + synchronization)
    → scrum-of-scrums.md (Scrum Master coordination)
    → gestion-impediments-art.md (cross-team unblocking)

  ... STEER THE ART'S PERFORMANCE?
    → metriques-art.md (PI Predictability + Flow + DORA)
    → ../safe/inspect-adapt.md (quarterly, end of PI — shared PO-SAFE / PM-SAFE)
    → amelioration-continue-art.md (ART Kaizen)
```
