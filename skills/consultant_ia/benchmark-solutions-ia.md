# Skill — Benchmark Solutions IA
> Certifications : AWS CCP · Google Cloud Digital Leader · Azure AZ-900

## Objectif
Comparer les solutions IA du marché pour recommander le meilleur choix selon le contexte client.

### Make vs. Buy IA
| Critère | Build (développement custom) | Buy (solution éditeur) |
|---|---|---|
| Coût initial | Élevé | Faible |
| Flexibilité | Totale | Limitée |
| Time-to-market | Lent (6-18 mois) | Rapide (1-3 mois) |
| Dépendance | Interne | Éditeur |
| Maintenance | Équipe interne | Éditeur |

## Méthode de benchmark
1. Définir les critères pondérés (doit-haves vs. nice-to-haves)
2. Shortlist : 3-5 solutions maximum
3. PoC ou démo technique sur un cas d'usage réel
4. Évaluation sur grille pondérée
5. Analyse TCO (Total Cost of Ownership) sur 3 ans
6. Recommandation argumentée

## Livrables
- Grille de benchmark pondérée
- Résultats PoC / démo comparatifs
- Analyse TCO 3 ans
- Recommandation avec argumentaire (1 page)

## Format de sortie
Précise : catégorie de solution · contraintes (RGPD, budget, stack existante) · critères prioritaires · délai de décision
