# Skill SAFe — OKR

## Format OKR
```
OBJECTIVE : [Qualitatif — inspirant — orienté résultat]

Key Result 1 : [Quantitatif — mesurable — baseline + cible]
Key Result 2 : [Quantitatif — mesurable — baseline + cible]
Key Result 3 : [Quantitatif — mesurable — baseline + cible]
```

## Exemple
```
OBJECTIVE : Devenir la référence du service client digital B2B

KR1 : Augmenter le NPS client de 32 à 50 d'ici fin Q3
KR2 : Réduire le temps de résolution tickets de 48h à 24h
KR3 : Atteindre 85% d'adoption de l'espace client self-service
```

## Alignement SAFe
```
Strategic Themes (Portfolio)
  └── OKR Stratégiques
        └── PI Objectives
              └── Features
                    └── User Stories
```

## Règles OKR
- 1 Objective = 3 à 5 Key Results maximum
- Key Results : mesurables, pas des tâches
- Objectif ambitieux mais atteignable à 70%
- Revue mensuelle de l'avancement
- Bilan en fin de PI / trimestre
