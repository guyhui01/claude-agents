## Choisir le bon skill — Arbre de décision

```
Tu veux ...

  ... COMPRENDRE LES UTILISATEURS ?
    → user-research.md (interviews + observations)
    → personas-jtbd.md (personas + Jobs To Be Done)
    → journey-mapping.md (parcours)
    → benchmark-concurrent.md (état du marché)

  ... CONCEVOIR L'EXPÉRIENCE ?
    → architecture-information.md (structure)
    → wireframing.md (premières maquettes)
    → prototypage-figma.md (interactivité)
    → design-system.md (cohérence)

  ... DESIGN AVEC L'IA ?
    → design-for-ai.md (chat UI, voice UI, prompts)

  ... VALIDER LE DESIGN ?
    → tests-utilisateurs.md (qualitatif)
    → ab-testing.md (quantitatif)
    → audit-ux-heuristiques.md (expert review)
    → accessibilite-wcag.md (conformité RGAA/WCAG)
    → metriques-ux.md (SUS / HEART / NPS)

  ... TRAVAILLER AVEC L'ÉQUIPE ?
    → design-handoff.md (vers les devs)
    → design-agile-safe.md (intégration sprint)
    → facilitation-ateliers.md (Design Sprint, Co-design)
    → storytelling-stakeholders.md (présenter au CODIR)
```
