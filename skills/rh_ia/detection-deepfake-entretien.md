# Skill — Deepfake & AI Voice Detection in Interviews
> Certifications: SHRM-CP (SHRM) · ATD CPTD (ATD) · CIPD Level 5 (CIPD)

## Objective
Identify candidates using an AI-cloned voice, a video deepfake avatar, or a real-time AI assistant during remote interviews, to guarantee the authenticity of the assessment and protect the hiring decision.

## Overview of remote-interview fraud

```
FRAUD TYPE 1 — VOICE CLONING
──────────────────────────────────────────────────────
Principle : Candidate uses ElevenLabs, Resemble AI, or Descript
            to synthesize a different voice in real time
Real case : IT remote-worker employment-fraud schemes using fake AI workers,
            documented by the US DOJ and Mandiant (2023-2024) — spoofed voice/identity
Detection : Abnormal latency · audio artifacts · overly uniform voice
            No breathing, laughter, or natural hesitations

FRAUD TYPE 2 — VIDEO DEEPFAKE
──────────────────────────────────────────────────────
Principle : Real-time face replacement (DeepFaceLive,
            Avatarify) or use of an AI avatar (HeyGen live)
Real case : LinkedIn/Google interviews where the displayed candidate ≠ real identity
Detection : Blurry face edges · abnormal blinking · perfect
            background but slightly desynced face

FRAUD TYPE 3 — REAL-TIME AI COPILOT
──────────────────────────────────────────────────────
Principle : Candidate reads answers generated by Claude/ChatGPT
            via a second screen or earpiece (Interview Cram, Final Round AI)
Real case : Micro-pauses before every answer · overly structured answers
Detection : No spontaneous answer, uniform latency
            No "I don't know", always a perfect answer

FRAUD TYPE 4 — CANDIDATE SUBSTITUTION
──────────────────────────────────────────────────────
Principle : Someone else takes the interview in the candidate's place
Real case : Observed in fully remote hiring, all contexts
Detection : Live ID-document check · personal questions
            Mismatch between interview voice and qualification-call voice
```

## Audio warning signals — AI voice

```
TYPICAL AUDIO ANOMALIES OF A SYNTHETIC VOICE
──────────────────────────────────────────────────────
· Systematic latency before every answer (order of magnitude, ~1-2s) — judge in context
· Overly regular prosody: constant pace, no speeding up/slowing down
· No natural disfluencies: "um", "well", "you know"
· No ambient noise consistent with the stated location
· Sibilant consonants or metallic artifacts on "s" and "f"
· Answer starting from scratch on each question (no narrative continuity)
· Inability to be interrupted and resume naturally
```

## Video warning signals — Deepfake

```
TYPICAL VISUAL ANOMALIES OF A DEEPFAKE
──────────────────────────────────────────────────────
· Blurry or slightly pixelated face/ear edges
· Blinking too regular or absent
· Very limited head movement (model fixed on one angle)
· Lips slightly out of sync with the audio
· Background too perfect (virtual) but inconsistent facial lighting
· Face resolution ≠ body/clothing resolution
· Artifacts during fast movement (turning the head)
```

## Live verification protocols

```
PROTOCOL 1 — IMPROVISATION TEST (all remote interviews)
──────────────────────────────────────────────────────
Ask on the spot:
  · "Show me your workspace" (360° camera rotation)
  · "Spell your last name letter by letter"
  · "Read the number now showing on my screen" (display a code)
  · Switch language suddenly (FR → EN or vice versa)
  · Ultra-specific question about a CV project: "What was the exact
    name of your manager at [company]?"

PROTOCOL 2 — LIVE IDENTITY VERIFICATION
──────────────────────────────────────────────────────
  · Ask for ID card / passport visible to the camera
  · Compare the live face with the ID photo
  · Compare with the LinkedIn photo (if the profile is authenticated)
  · For sensitive roles: Veriff or Persona session before the interview

PROTOCOL 3 — AI COPILOT DETECTION
──────────────────────────────────────────────────────
  · Ask a very contextual question about today's news
  · Ask for a past mistake: a real memory has precise details
  · Interrupt mid-sentence and ask them to continue
  · "No right answer" question: observe the reaction to ambiguity
  · Ask them to re-explain differently what they just said
```

## Scoring grid — Interview authenticity

| Indicator | Score (0-3) | Weight | Comment |
|---|---|---|---|
| Natural voice fluidity | | 25% | |
| Visual consistency (lip/voice sync) | | 20% | |
| Answer spontaneity | | 20% | |
| Improvisation tests passed | | 20% | |
| Identity consistency (CV / LinkedIn / live) | | 15% | |
| **Total score** | | 100% | **/3** |

```
INTERPRETATION
──────────────────────────────────────────────────────
≥ 2.5 / 3  → Authentic interview — continue the process
1.5 - 2.4  → Moderate suspicion → in-person interview required
< 1.5      → Probable fraud → flag to the client, stop the process
```

## What to do when fraud is detected

```
PROCEDURE
──────────────────────────────────────────────────────
1. Don't accuse live — end the interview politely
   ("We have a technical issue, we'll get back to you")
2. Document: screenshots, audio recording (if GDPR consent)
3. Inform the client immediately with the analysis report
4. Archive in the CV database tagged "FRAUD DETECTED" + date
5. Do NOT re-contact the candidate — complaint risk
6. If proven harm (role filled then discovered) → legal HR report
```

## Deliverables
- Interview authenticity report (score + detailed observations)
- Recommendation: Authentic / Suspicious (in-person required) / Fraud detected
- Incident-handling procedure for the client
- Recruiter training: detection protocols (1h, in-person or remote)

## Output format
Specify: interview platform used (Teams, Zoom, Google Meet, HireVue), role concerned, criticality level, observations already noted by the recruiter.

## ⚖️ Compliance & non-discrimination
- Detection targets **technical and behavioral signals** (latency, artifacts, sync), **never** accent, presumed origin, or name sound (French Labor Code **L1132-1**).
- Biometric / identity verification = high-risk processing: **prior disclosure to the candidate** (GDPR; French Labor Code **L1221-8**), legal basis, limited retention period.
- A detection tool can produce **false positives**: never base a rejection on the automatic score alone → always a human judgment (in-person if in doubt).
- Biometric/deepfake recognition tools: watch for **AI Act (EU Regulation 2024/1689)** depending on the use.

## Anti-patterns
- ❌ Accuse a candidate of fraud live (legal risk) — end politely and document.
- ❌ Associate fraud with a nationality or accent (discrimination, L1132-1).
- ❌ Record the interview without disclosure or a GDPR legal basis.
- ❌ Rely 100% on a detection tool without human verification.
- ❌ Freeze numeric thresholds (latency, price) as absolute truths.
