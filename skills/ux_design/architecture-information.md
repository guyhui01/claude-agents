# Skill — Information Architecture
> Certifications: UXQB CPUX-F · IDF

## Objective
Organize and structure a product's content so that users find information easily.

## Techniques
- **Card sorting** (open / closed / hybrid): identify users' mental models
- **Tree testing**: validate the proposed navigation without a visual interface
- **Sitemap**: hierarchy of pages and content
- **Navigation patterns**: sidebar, tabs, breadcrumbs, mega-menu

## Deliverables
- Card sorting results (dendrogram, similarity matrix)
- Tree testing score (direct success, indirect success, failure)
- Annotated sitemap
- Navigation recommendations

## Recommended tools
Optimal Workshop · Maze · FigJam · Miro

## Output format
Specify: product type · content volume · target audience · existing research results

## Sources
- **Louis Rosenfeld, Peter Morville & Jorge Arango** — *Information Architecture for the Web and Beyond* (O'Reilly, 4th ed. 2015) — reference work ("polar bear book")
- **Donna Spencer** — *Card Sorting: Designing Usable Categories* (Rosenfeld Media, 2009) — the card sorting method
- **Dave O'Brien / Optimal Workshop** — formalization of *tree testing* (navigation validation without UI)
- **Jakob Nielsen** — *Mega Menus Work Well for Site Navigation* (NN/g) — navigation patterns

## Anti-patterns
- Modeling the IA on the internal org chart rather than on users' mental models
- Sitemap designed without validation (no card sorting or tree testing) = untested hypothesis
- Over-nesting: depth > 3 levels that degrades findability
- Menu labels in business jargon instead of the users' vocabulary
- Card sorting with too small a sample (< 15 participants for a reliable analysis)
