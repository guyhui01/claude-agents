# Skill — Portfolio Epics & Lean Portfolio Management
> Certifications: SAFe POPM 6 · SAFe LPM (Lean Portfolio Management)

## Objective
Manage strategic initiatives (Epics) at the Portfolio level and align them with the Value Streams.

## SAFe Portfolio hierarchy
```
Strategic Themes (Enterprise vision)
  └── Portfolio Epics (Business Epics + Enabler Epics)
        └── Capabilities / Features
              └── Stories
```

## Business Epic vs. Enabler Epic
- **Business Epic**: an initiative creating direct customer value (new market, new product)
- **Enabler Epic**: a technological or architectural initiative (migration, platform, security)

## Lean Business Case (LBC)
For each Epic entering the Portfolio Backlog:
- **Context**: problem or opportunity
- **Vision**: expected outcome
- **Business Outcome Hypothesis**: if we do X, we'll get Y, measurable by Z
- **Leading Indicators**: early signals of success
- **Non-financial Benefits**: customer satisfaction, risk reduction, quality improvement
- **Cost**: high-level estimate, not a precise commitment
- **Go / No-go criteria**: conditions to continue or stop

## Portfolio Kanban
```
Funnel → Review → Analyzing → Portfolio Backlog → Implementing → Done
```
- Limited WIP at each step
- Entry and exit criteria defined per step

## Deliverables
- Lean Business Case per strategic Epic
- Prioritized Portfolio Backlog (Jira Align / Targetprocess)
- Configured Portfolio Kanban
- Epic progress report (Epic burn-up)

## Output format
Specify: number of active Epics · relevant Value Streams · governance (LACE, portfolio sync cadence)
