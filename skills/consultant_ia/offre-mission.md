# Skill — Offre de Mission Freelance
> Certifications : CAP IABAC · Anthropic Claude Code in Action

## Objectif
Construire une offre de mission freelance complète et professionnelle pour les plateformes de portage ou les clients directs.

## Structure d'une offre de mission freelance
```
1. Titre de la mission
   - Accrocheur, précis, orienté valeur
   - Ex : "Product Owner IA Senior — Transformation IA CAC40"

2. Résumé de la mission (5 lignes max)
   - Contexte client
   - Objectif de la mission
   - Ce que vous apportez

3. Profil recherché / Offert
   - Compétences obligatoires
   - Compétences souhaitées
   - Certifications valorisées

4. Détail des prestations
   - Livrables par phase
   - Méthodologie
   - Indicateurs de succès

5. Modalités
   - Durée (en jours ou mois)
   - Rythme (temps plein, partiel, remote)
   - Lieu (sur site, hybride, full remote)
   - TJM et conditions

6. Profil du prestataire (Guy HUIBONHOA)
   - 20 ans d'expérience MOA / PO
   - Certifications (PSPO1, SAFe6, Claude Code)
   - Références clients (Orange, CHANEL, Accor, CA-CIB)
```

## Pitch LinkedIn pour attirer les missions
```
🎯 [Titre de votre expertise]
🏆 [Certification ou réalisation marquante]
💼 [Expérience en chiffres : 20 ans, 15 projets...]
🚀 [Ce que vous apportez concrètement]
📩 [Call to action : disponible pour missions dès...]
```

## Livrables
- Offre de mission complète (format Malt / PDF)
- Pitch court (3-5 lignes) pour réseaux
- Template de proposition de TJM
- CV consultants adapté à la mission

## Format de sortie
Précise : type de mission · secteur client · durée · modalités (remote/sur site) · TJM cible
