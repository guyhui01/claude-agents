# SAFe Skill — OKR

> Certification: SAFe POPM 6
> Agents: AGENT-PO-SAFE.md · AGENT-PRODUCT-MANAGER-SAFE.md

## OKR format
```
OBJECTIVE: [Qualitative — inspiring — outcome-oriented]

Key Result 1: [Quantitative — measurable — baseline + target]
Key Result 2: [Quantitative — measurable — baseline + target]
Key Result 3: [Quantitative — measurable — baseline + target]
```

## Example
```
OBJECTIVE: Become the reference for B2B digital customer service

KR1: Raise customer NPS from 32 to 50 by the end of Q3
KR2: Reduce ticket resolution time from 48h to 24h
KR3: Reach 85% adoption of the self-service customer portal
```

## SAFe alignment
```
Strategic Themes (Portfolio)
  └── Strategic OKRs
        └── PI Objectives
              └── Features
                    └── User Stories
```

## OKR rules
- 1 Objective = 3 to 5 Key Results maximum
- Key Results: measurable, not tasks
- Ambitious objective but achievable at 70%
- Monthly progress review
- Wrap-up at the end of the PI / quarter
