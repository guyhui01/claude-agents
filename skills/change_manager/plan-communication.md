# Skill — Change Communication Plan
> Certifications: PROSCI Change Management (PROSCI), CCMP (ACMP), PMI-ACP (PMI)
> Agent: AGENT-CHANGE-MANAGER.md

## Objective
Build a structured communication plan to support a change — key messages per population, fit-for-purpose channels, schedule, reception indicators — to ensure the right people get the right message at the right time.

## Template — Full Communication Plan

### 1. Communication strategy

```
COMMUNICATION OBJECTIVES
───────────────────────────────────────────────────────
1. Create Awareness of the change
2. Generate the Desire to take part and support
3. Share the Knowledge about the WHAT and HOW
4. Prepare the Ability to adopt
5. Reinforce after go-live

KEY MESSAGES
───────────────────────────────────────────────────────
Message 1 (Awareness)  : "Why this change, now?"
Message 2 (Desire)     : "What's in it for me concretely?"
Message 3 (Knowledge)  : "How does it work, how do I get trained?"
Message 4 (Ability)    : "I'm supported, I'm not alone"
Message 5 (Reinf.)     : "My first wins are recognized"
```

### 3. Key messages per population

```
LEADERSHIP / SPONSORS
────────────────────────────────────────────────────
Message : "This project is strategic for our competitiveness.
           It is backed at the highest level."
Emphasis: ROI, market positioning, AI leadership
Channel : Leadership note, Steering Committee

MANAGERS
────────────────────────────────────────────────────
Message : "You are the first ambassadors of the change.
           Your teams are watching you."
Emphasis: Facilitation role, available resources, quick wins
Channel : Dedicated session, manager kit

END USERS
────────────────────────────────────────────────────
Message : "AI will save you time on repetitive tasks
           — not replace you."
Emphasis: Concrete benefits, support, training
Channel : Practical guide, live demo, Slack
```
