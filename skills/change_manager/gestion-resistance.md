# Skill — Gestion des Résistances au Changement
> Certifications : PROSCI Change Management (PROSCI), CCMP (ACMP), SAFe 6 Agilist (Scaled Agile)

## Objectif
Identifier, diagnostiquer et traiter les résistances au changement — comprendre leurs causes profondes, segmenter les profils résistants et mettre en place des plans d'action ciblés pour transformer les résistants en ambassadeurs.

## Taxonomie des résistances

```
TYPE 1 — RÉSISTANCE PAR IGNORANCE
  Cause   : "Je ne comprends pas pourquoi ce changement est nécessaire"
  Signal  : Questions répétées, absence aux sessions d'information
  Action  : Communication renforcée, Q&A ciblés, sponsor visible

TYPE 2 — RÉSISTANCE PAR PEUR
  Cause   : "J'ai peur de perdre mon emploi / mes compétences / mon statut"
  Signal  : Rumeurs, silence lors des réunions, absentéisme
  Action  : Clarifier le message (augmentation vs remplacement), coaching 1-1

TYPE 3 — RÉSISTANCE PAR DÉSACCORD
  Cause   : "Je pense que c'est une mauvaise décision"
  Signal  : Critiques publiques, contre-propositions, escalades
  Action  : Écoute active, impliquer dans la solution, expliquer le WHY

TYPE 4 — RÉSISTANCE PAR SATURATION
  Cause   : "J'ai trop de changements en même temps, je suis épuisé"
  Signal  : Baisse de performance, cynisme, démotivation générale
  Action  : Séquencer les changements, quick wins, valoriser les efforts

TYPE 5 — RÉSISTANCE PAR INTÉRÊT PERSONNEL
  Cause   : "Ce changement menace mon pouvoir / mes avantages actuels"
  Signal  : Blocages actifs, lobbying contre, silence stratégique
  Action  : Négociation, impliquer dans la gouvernance, sponsor en soutien
```

## Matrice de diagnostic — Résistants

| Profil | Type résistance | Niveau influence | Stratégie |
|---|---|---|---|
| Manager bloqueur | Désaccord + Intérêt | Fort | Entretien sponsor + implication gouvernance |
| Utilisateur passif | Ignorance + Peur | Faible | Communication ciblée + pair champion |
| Expert sceptique | Désaccord | Moyen | Associer à la conception + valoriser expertise |
| Manager épuisé | Saturation | Moyen | Alléger charge, séquencer, reconnaître effort |

## Plan d'action — Gestion des résistances

```
ÉTAPE 1 — ÉCOUTER AVANT D'AGIR
  Mener des entretiens individuels (30 min, confidentiel)
  Questions clés :
  - "Qu'est-ce qui vous préoccupe dans ce projet ?"
  - "Qu'est-ce qui vous aiderait à avancer ?"
  - "Qu'est-ce qui devrait être différent ?"

ÉTAPE 2 — QUALIFIER LA RÉSISTANCE
  Type ? Niveau d'influence ? Risque pour le projet ?
  → Prioriser les résistants à fort impact

ÉTAPE 3 — PLAN D'ACTION CIBLÉ
  Par profil : communication / coaching / implication / négociation

ÉTAPE 4 — TRANSFORMER EN AMBASSADEUR
  Valoriser publiquement le changement de position
  Confier un rôle de champion interne
```

## Techniques de facilitation

```
TECHNIQUE 1 — Écoute active (Carl Rogers)
  Reformuler, valider l'émotion, ne pas contre-argumenter d'emblée
  "J'entends que vous êtes préoccupé par... c'est légitime."

TECHNIQUE 2 — Questionnement socratique
  Questions ouvertes pour faire émerger la solution
  "Qu'est-ce qui devrait se passer pour que vous soyez à l'aise ?"

TECHNIQUE 3 — Impliquer le résistant dans la solution
  "Votre expertise est précieuse — comment ferait-on mieux selon vous ?"
  → Transformer l'opposition en contribution

TECHNIQUE 4 — Quick wins visibles
  Montrer rapidement des résultats concrets pour réduire les doutes
  → Sélectionner des pilotes enthousiastes comme premiers ambassadeurs
```

## Livrables
- Registre des résistances (type, profil, stratégie)
- Plan d'entretiens de diagnostic
- Plan d'action ciblé par profil
- Suivi de l'évolution des résistances

## Format de sortie
Précise : nature du changement, profils identifiés comme résistants, niveau d'influence, contexte organisationnel.
