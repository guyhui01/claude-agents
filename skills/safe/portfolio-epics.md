# Skill — Portfolio Epics & Lean Portfolio Management
> Certifications : SAFe POPM 6 · SAFe LPM (Lean Portfolio Management)

## Objectif
Gérer les initiatives stratégiques (Epics) au niveau Portfolio et les aligner sur les Value Streams.

## Hiérarchie Portfolio SAFe
```
Strategic Themes (Vision d'entreprise)
  └── Portfolio Epics (Business Epics + Enabler Epics)
        └── Capabilities / Features
              └── Stories
```

## Business Epic vs. Enabler Epic
- **Business Epic** : initiative créant de la valeur client directe (nouveau marché, nouveau produit)
- **Enabler Epic** : initiative technologique ou architecturale (migration, plateforme, sécurité)

## Lean Business Case (LBC)
Pour chaque Epic entrant dans le Portfolio Backlog :
- **Contexte** : problème ou opportunité
- **Vision** : résultat attendu
- **Business Outcome Hypothesis** : si nous faisons X, nous obtiendrons Y, mesurable par Z
- **Leading Indicators** : signaux précoces de succès
- **Non-financial Benefits** : satisfaction client, réduction risque, amélioration qualité
- **Coût** : estimation haute, pas un engagement précis
- **Go / No-go criteria** : conditions pour continuer ou stopper

## Portfolio Kanban
```
Funnel → Review → Analyzing → Portfolio Backlog → Implementing → Done
```
- WIP limité à chaque étape
- Critères d'entrée et sortie définis par étape

## Livrables
- Lean Business Case par Epic stratégique
- Portfolio Backlog priorisé (Jira Align / Targetprocess)
- Portfolio Kanban configuré
- Rapport de progression des Epics (Epic burn-up)

## Format de sortie
Précise : nombre d'Epics actifs · Value Streams concernés · gouvernance (LACE, portfolio sync cadence)
