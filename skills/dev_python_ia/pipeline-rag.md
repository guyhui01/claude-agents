## Objective

## Full pipeline

### 1. Document ingestion
```python
# LangChain v0.2+: the text_splitter lives in a separate package
from langchain_community.document_loaders import PyPDFLoader, DirectoryLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter

loader = DirectoryLoader("./docs", glob="**/*.pdf", loader_cls=PyPDFLoader)
docs = loader.load()

splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=200,
    separators=["\n\n", "\n", ". ", " ", ""],  # priority order
)
chunks = splitter.split_documents(docs)
```

### 2. Embedding & storage
```python
# Option A: Voyage AI (recommended in 2026 — best quality/cost ratio for French)
from langchain_voyageai import VoyageAIEmbeddings
embeddings = VoyageAIEmbeddings(model="voyage-3-large", batch_size=128)

# Option B: OpenAI (mainstream alternative)
# from langchain_openai import OpenAIEmbeddings
# embeddings = OpenAIEmbeddings(model="text-embedding-3-large")

from langchain_qdrant import QdrantVectorStore
vectorstore = QdrantVectorStore.from_documents(chunks, embeddings, url="http://localhost:6333")
```

> ℹ️ To use Claude (Anthropic) as the generator, embeddings must come from another provider — Anthropic does not offer a native embeddings API. Voyage AI is their recommended official partner.

### 3. Retrieval with reranking
```python
from langchain.retrievers import ContextualCompressionRetriever
from langchain_cohere import CohereRerank

base_retriever = vectorstore.as_retriever(search_kwargs={"k": 10})
reranker = CohereRerank(model="rerank-multilingual-v3.0", top_n=4)
retriever = ContextualCompressionRetriever(base_compressor=reranker, base_retriever=base_retriever)
```

### 4. Generation with sources
```python
from langchain_core.runnables import RunnablePassthrough

rag_chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)
```

## Advanced optimizations
- **Hybrid search**: BM25 + vector via EnsembleRetriever
- **Parent-child chunking**: retrieve the parent for more context
- **HyDE**: generate a hypothetical doc before embedding the query
- **Multi-query**: generate several query variants for higher recall

## Evaluation with RAGAs

```python
from datasets import Dataset
from ragas import evaluate
from ragas.metrics import (
    faithfulness,           # is the LLM hallucinating relative to the context?
    answer_relevancy,       # is the answer relevant to the question?
    context_precision,      # are the retrieved chunks useful?
    context_recall,         # did retrieval find all the needed info?
)

# Eval dataset = list of questions with ground truth (curate manually)
eval_data = {
    "question": ["What is the return policy?", "What is the SLA?"],
    "answer": [rag_chain.invoke(q) for q in questions],            # generated by the RAG
    "contexts": [[doc.page_content for doc in retriever.invoke(q)] for q in questions],
    "ground_truth": ["30 days, no questions asked", "4 business hours"],   # human reference
}
dataset = Dataset.from_dict(eval_data)

results = evaluate(
    dataset,
    metrics=[faithfulness, answer_relevancy, context_precision, context_recall],
)
print(results)
# {'faithfulness': 0.92, 'answer_relevancy': 0.87, 'context_precision': 0.81, 'context_recall': 0.76}
```

**Recommended production thresholds**: faithfulness ≥ 0.90 (anti-hallucination), context_recall ≥ 0.80 (coverage). Below that → revisit chunking or reranking.
