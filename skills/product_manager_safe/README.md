## Choosing the right skill — Decision tree

```
You want to ...

  ... DEFINE THE PROGRAM VISION?
    → vision-strategie-produit.md (Program)
    → enterprise-product-vision.md (multi-ART enterprise)
    → market-analysis.md (competitive)

  ... PLAN FOR THE LONG TERM?
    → roadmap-programme.md (18-24 months)
    → release-strategy.md (go-to-market)

  ... PRIORITIZE THE INVESTMENT?
    → economic-framework-pm.md (WSJF + LBC)

  ... STEER THE ORG. TRANSFORMATION?
    → scaling-product-ownership.md (multi-team)
    → product-operating-model.md (target model)
    → stakeholder-alignment-pm.md (alignment)

  ... DECOMPOSE AN EPIC?
    → see skills/safe/epic-hypothesis-mvp.md + epic-to-feature-splitting.md
```
