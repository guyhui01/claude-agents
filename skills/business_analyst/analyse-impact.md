# Skill — Analyse d'Impact & Conduite du Changement
> Certifications : PROSCI Change Management · IIBA AAC · PMI-PBA

## Objectif
Mesurer les impacts d'un projet sur l'organisation et définir le plan de conduite du changement associé.

## Analyse d'impact — Dimensions
| Dimension | Questions | Impact potentiel |
|---|---|---|
| **Processus** | Quels processus changent ? | Fort / Moyen / Faible |
| **Organisation** | Quels rôles évoluent ? | Fort / Moyen / Faible |
| **SI / Outils** | Quels systèmes sont impactés ? | Fort / Moyen / Faible |
| **Compétences** | Quelles formations sont nécessaires ? | Fort / Moyen / Faible |
| **Culture** | Quels comportements doivent changer ? | Fort / Moyen / Faible |

## Modèle ADKAR (PROSCI)
| Étape | Objectif | Actions |
|---|---|---|
| **Awareness** | Comprendre pourquoi le changement est nécessaire | Communication, ateliers |
| **Desire** | Vouloir participer au changement | Engagement, champions |
| **Knowledge** | Savoir comment changer | Formation, documentation |
| **Ability** | Pouvoir changer (compétences) | Coaching, support |
| **Reinforcement** | Maintenir le changement | Feedback, reconnaissance |

## Plan de conduite du changement
```
1. Diagnostic de l'état de préparation au changement
2. Identification des populations impactées (cartographie)
3. Analyse des résistances potentielles
4. Plan de communication (qui, quoi, quand, comment)
5. Plan de formation (modules, populations, calendrier)
6. Plan d'accompagnement (champions, référents)
7. Indicateurs de suivi (taux d'adoption, satisfaction)
```

## Courbe du changement (Kübler-Ross adaptée)
```
Choc → Déni → Résistance → Exploration → Engagement → Intégration
```
Identifier où se trouve chaque population et adapter les actions.

## Livrables
- Matrice d'impact (populations × dimensions)
- Plan de conduite du changement
- Plan de communication
- Plan de formation
- Tableau de bord d'adoption

## Format de sortie
Précise : nature du projet (IA, SI, organisationnel) · populations impactées · délai · niveau de résistance estimé
