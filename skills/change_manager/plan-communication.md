# Skill — Plan de Communication du Changement
> Certifications : PROSCI Change Management (PROSCI), CCMP (ACMP), PMI-ACP (PMI)
> Agent : AGENT-CHANGE-MANAGER.md

## Objectif
Construire un plan de communication structuré pour accompagner un changement — messages clés par population, canaux adaptés, calendrier, indicateurs de réception — pour garantir que les bonnes personnes reçoivent le bon message au bon moment.

## Template — Plan de Communication Complet

### 1. Stratégie de communication

```
OBJECTIFS DE COMMUNICATION
───────────────────────────────────────────────────────
1. Créer la Awareness (Conscience) du changement
2. Générer le Desire (Désir) de participer et soutenir
3. Partager la Knowledge (Connaissance) sur le QUOI et COMMENT
4. Préparer l'Ability (Capacité) à adopter
5. Renforcer (Reinforcement) après le go-live

MESSAGES CLÉS
───────────────────────────────────────────────────────
Message 1 (Awareness)  : "Pourquoi ce changement, maintenant ?"
Message 2 (Desire)     : "Qu'est-ce que ça m'apporte concrètement ?"
Message 3 (Knowledge)  : "Comment ça marche, comment me former ?"
Message 4 (Ability)    : "Je suis accompagné, je ne suis pas seul"
Message 5 (Reinf.)     : "Mes premiers succès sont reconnus"
```

### 3. Messages clés par population

```
DIRECTION / SPONSORS
────────────────────────────────────────────────────
Message : "Ce projet est stratégique pour notre compétitivité.
           Il est soutenu au plus haut niveau."
Accent  : ROI, positionnement marché, leadership IA
Canal   : Note de direction, Steering Committee

MANAGERS
────────────────────────────────────────────────────
Message : "Vous êtes les premiers ambassadeurs du changement.
           Vos équipes vous regardent."
Accent  : Rôle de facilitation, ressources disponibles, quick wins
Canal   : Session dédiée, kit manager

UTILISATEURS FINAUX
────────────────────────────────────────────────────
Message : "L'IA va vous faire gagner du temps sur les tâches
           répétitives — pas vous remplacer."
Accent  : Bénéfices concrets, accompagnement, formations
Canal   : Guide pratique, démo live, Slack
```

### 5. Indicateurs de suivi communication

| KPI | Cible | Mesure |
|---|---|---|
| Taux d'ouverture emails | > 75% | Outil emailing |
| Taux participation sessions Q&A | > 80% managers | Feuilles émargement |
| Score de compréhension (sondage J-7) | > 70% "Je comprends pourquoi" | Survey Typeform |
| Taux de lecture guide utilisateurs | > 60% | Analytics intranet |

## Livrables
- Plan de communication complet (tableau)
- Messages clés par population
- Calendrier frise temporelle
- KPIs de suivi

## Format de sortie
Précise : nature du changement, populations, date de go-live, canaux disponibles (intranet, Slack, email, présentiel).
