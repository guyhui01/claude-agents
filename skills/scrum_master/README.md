## Choisir le bon skill — Arbre de décision

```
Tu veux ...

  ... ANIMER UNE CÉRÉMONIE SCRUM ?
    → facilitation-ceremonies (vue d'ensemble + agendas Planning/Daily/Review/Rétro/Refinement)
    → retrospective-avancee (formats variés : Sailboat, Fishbone, Timeline, Prime Directive)
    → planning-poker (estimation collective Fibonacci, alternatives, remote)

  ... COACHER L'ÉQUIPE OU LE PO ?
    → coaching-equipe / coaching-po-sm
    → conflict-resolution (si tensions)

  ... PILOTER LA QUALITÉ DU SYSTÈME AGILE ?
    → gestion-impediments / metriques-agiles
    → amelioration-continue (Kaizen continu)

  ... SCALER (SAFe) ?
    → scaling-safe-ssm (rôle SSM dans l'ART)
    → community-of-practice (CoP transverses)

  ... CONDUIRE UNE TRANSFO ?
    → change-management-agile (Kotter + ADKAR)
    → onboarding-agile (nouvelle équipe)
```
