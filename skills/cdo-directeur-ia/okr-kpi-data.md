# Skill — Data-AI OKR & KPI Framework

> Certifications: OKR Professional (Perdoo / What Matters), CDMP Data Management 2026, Google Analytics Certified, Tableau Desktop Specialist

## Objective

Define a complete OKR framework for Data-AI teams, with operational KPIs per function (Data Engineering, Data Science, MLOps, Analytics) and a North Star Metric aligned with value creation.

## Data-AI OKR framework architecture

### 4-level hierarchy

```
Level 1 — COMPANY (annual)
    "Become the data-driven leader of our sector"
        │
Level 2 — CDO / DATA LEADERSHIP (quarterly)
    "Leverage data to accelerate growth"
        │
Level 3 — DATA TEAMS (quarterly)
    Data Engineering | Data Science | Analytics | Governance
        │
Level 4 — INDIVIDUAL (monthly)
    Personal objectives aligned with the team
```

## Data-AI North Star Metric

### Definition and calculation

```
Proposed NORTH STAR METRIC:
"Data Value Score" (DVS)

Formula:
DVS = (Num_use_cases_prod × Avg_value_€k)
      × Data_quality_%
      × Adoption_rate_%

Example Q3 2026:
DVS = (8 × 380) × 0.942 × 0.65
    = 3,040 × 0.942 × 0.65
    = 1,863 (points)

Target end of 2027: DVS > 5,000

Why this metric?
→ Captures quantity (# use cases)
→ Captures quality (DQ score)
→ Captures adoption (real usage rate)
→ Avoids vanity metrics (# models trained ≠ value)
```
