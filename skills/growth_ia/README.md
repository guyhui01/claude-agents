## Choosing the right skill — Decision tree

```
You want to ...

  ... ACQUIRE NEW USERS?
    → acquisition-seo-sem.md (SEO + SEM + paid social)

  ... DRIVE GROWTH WITH DATA?
    → product-analytics.md (funnels, cohorts, North Star)
    → attribution-ltv-cac.md (CAC, LTV, payback)
    → growth-frameworks.md (AARRR, ICE, HEART)

  ... EXPERIMENT?
    → experimentation-ab-testing.md (rigorous design + statistical power)

  ... ENGAGE & RETAIN?
    → lifecycle-marketing.md (onboarding, retention, churn)

  ... ACCELERATE WITH AI?
    → ia-personalisation.md (recommendations, ML scoring)
    → automation-growth.md (n8n workflows + AI)
```
