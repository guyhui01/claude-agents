# Skill — Engagement des Parties Prenantes au Changement
> Certifications : PROSCI Change Management (PROSCI), PMP (PMI), PRINCE2 Practitioner (Axelos)

## Objectif
Identifier, analyser et engager les parties prenantes d'un changement — comprendre leur positionnement, construire un plan d'engagement ciblé et piloter l'évolution de leur soutien tout au long du projet.

## Matrice de positionnement des parties prenantes

```

NEUTRE   │ Informer          │ Convaincre (PRIORITÉ 2)

──────────────────────────────────────────────────────────
```

## Plan d'engagement par profil

### Sponsors — Maintenir et mobiliser

```
ACTIONS
────────────────────────────────────────────────
✓ Briefings réguliers (avancement, risques)
✓ Préparer les messages clés pour leurs communications
✓ Solliciter leur présence aux moments clés (kick-off, go-live)
✓ Reporting changement au Steering Committee mensuel
✓ Valoriser leur soutien publiquement

SIGNAUX D'ALERTE
────────────────────────────────────────────────
⚠ Absence aux événements clés → relancer + comprendre
⚠ Messages contradictoires → aligner avec le Change Manager
```

### Opposants influents — Traiter en priorité

```
ACTIONS
────────────────────────────────────────────────
✓ Entretien individuel confidentiel (écoute active)
✓ Comprendre les objections profondes (ADKAR D)
✓ Impliquer dans la conception ou la gouvernance
✓ Trouver un gain personnel à leur participation
✓ Escalader au sponsor si blocage persistant

SCRIPT D'ENTRETIEN
────────────────────────────────────────────────
"Je voudrais comprendre vos préoccupations. 
 Qu'est-ce qui vous semble problématique dans ce projet ?
 Qu'est-ce qui devrait être différent pour que vous soyez à l'aise ?"
```
