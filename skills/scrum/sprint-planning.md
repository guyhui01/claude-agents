# Skill Scrum — Sprint Planning

## Durée : 2h (sprint de 2 semaines)

### Partie 1 — Quoi ? (1h)
- PO présente les US prioritaires (DOR validée)
- Équipe pose des questions de clarification
- PO confirme le Sprint Goal

### Partie 2 — Comment ? (1h)
- Équipe découpe les US en tâches techniques
- Estimation en heures
- Vérification de la capacité

## Sprint Goal — Format
```
Pour [persona principal],
Nous allons livrer [capacité clé],
Afin d'atteindre [bénéfice mesurable].
```

## Calcul capacité
```
Capacité = (Jours ouvrés × membres) - congés - réunions - dette tech
Vélocité cible = moyenne des 3 derniers sprints
```

## Checklist Sprint Planning
- [ ] Backlog ordonné, DOR validée sur les US planifiées
- [ ] Sprint Goal rédigé et accepté par l'équipe
- [ ] US découpées en tâches dans Jira
- [ ] Capacité vérifiée et acceptée
- [ ] Dépendances signalées
