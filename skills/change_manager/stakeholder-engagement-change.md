# Skill — Stakeholder Engagement in Change
> Certifications: PROSCI Change Management (PROSCI), PMP (PMI), PRINCE2 Practitioner (Axelos)
> Agent: AGENT-CHANGE-MANAGER.md

## Objective
Identify, analyze and engage the stakeholders of a change — understand their stance, build a targeted engagement plan and steer the evolution of their support throughout the project.

## Stakeholder positioning matrix

```
ANALYSIS GRID
──────────────────────────────────────────────────────────
          │ LOW INFLUENCE     │ HIGH INFLUENCE
─────────────────────────────────────────────────────────
OPPONENT  │ Monitor           │ Manage actively (PRIORITY 1)
NEUTRAL   │ Inform            │ Win over (PRIORITY 2)
SUPPORTER │ Mobilize          │ Leverage as a sponsor
──────────────────────────────────────────────────────────
```

## Engagement plan per profile

### Sponsors — Maintain and mobilize

```
ACTIONS
────────────────────────────────────────────────
✓ Regular briefings (progress, risks)
✓ Prepare key messages for their communications
✓ Request their presence at key moments (kick-off, go-live)
✓ Change reporting at the monthly Steering Committee
✓ Value their support publicly

WARNING SIGNS
────────────────────────────────────────────────
⚠ Absence at key events → follow up + understand
⚠ Contradictory messages → align with the Change Manager
```

### Influential opponents — Address as a priority

```
ACTIONS
────────────────────────────────────────────────
✓ Confidential individual interview (active listening)
✓ Understand the deep objections (ADKAR D)
✓ Involve in the design or the governance
✓ Find a personal gain in their participation
✓ Escalate to the sponsor if the blocker persists

INTERVIEW SCRIPT
────────────────────────────────────────────────
"I'd like to understand your concerns.
 What seems problematic to you about this project?
 What would need to be different for you to be comfortable?"
```
