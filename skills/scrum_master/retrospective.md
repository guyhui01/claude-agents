# Skill Scrum — Rétrospective

## Durée : 1h30

| Étape | Durée |
|---|---|
| Check-in (météo de l'équipe) | 5 min |
| Rappel des faits du sprint | 15 min |
| Discussion (format choisi) | 30 min |
| Plan d'actions | 30 min |
| Check-out | 10 min |

## Formats disponibles

### Start / Stop / Continue
```
START   : Que devrions-nous commencer à faire ?
STOP    : Que devrions-nous arrêter de faire ?
CONTINUE: Que devrions-nous continuer à faire ?
```

### 4L
```
LIKED      : Ce que j'ai apprécié
LEARNED    : Ce que j'ai appris
LACKED     : Ce qui manquait
LONGED FOR : Ce que j'aurais voulu
```

### Mad / Sad / Glad
```
MAD  : Ce qui m'a frustré
SAD  : Ce qui m'a déçu
GLAD : Ce qui m'a rendu heureux
```

## Plan d'actions SMART
```
Action : [description précise]
Responsable : [prénom]
Délai : [date ou sprint cible]
Mesure : [comment on sait que c'est fait]
Statut : ☐ À faire  ☐ En cours  ☐ Terminé
```

## Règle d'or
Max 3 actions par rétro — qualité > quantité
Chaque action a un responsable nommé
