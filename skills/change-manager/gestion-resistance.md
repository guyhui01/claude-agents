# Skill — Managing Resistance to Change
> Certifications: PROSCI Change Management (PROSCI), CCMP (ACMP), SAFe 6 Agilist (Scaled Agile)
> Agent: AGENT-CHANGE-MANAGER.md

## Objective
Identify, diagnose and address resistance to change — understand its root causes, segment the resistant profiles and set up targeted action plans to turn resisters into ambassadors.

## Resistance taxonomy

```
TYPE 1 — RESISTANCE FROM IGNORANCE
  Cause   : "I don't understand why this change is necessary"
  Signal  : Repeated questions, no-show at info sessions
  Action  : Reinforced communication, targeted Q&A, visible sponsor

TYPE 2 — RESISTANCE FROM FEAR
  Cause   : "I'm afraid of losing my job / my skills / my status"
  Signal  : Rumors, silence in meetings, absenteeism
  Action  : Clarify the message (augmentation vs replacement), 1-1 coaching

TYPE 3 — RESISTANCE FROM DISAGREEMENT
  Cause   : "I think it's a bad decision"
  Signal  : Public criticism, counter-proposals, escalations
  Action  : Active listening, involve in the solution, explain the WHY

TYPE 4 — RESISTANCE FROM SATURATION
  Cause   : "I have too many changes at once, I'm exhausted"
  Signal  : Performance drop, cynicism, general demotivation
  Action  : Sequence the changes, quick wins, value the efforts

TYPE 5 — RESISTANCE FROM SELF-INTEREST
  Cause   : "This change threatens my power / my current perks"
  Signal  : Active blocking, lobbying against, strategic silence
  Action  : Negotiation, involve in governance, sponsor backing
```

## Diagnosis matrix — Resisters

| Profile | Resistance type | Influence level | Strategy |
|---|---|---|---|
| Blocking manager | Disagreement + Self-interest | High | Sponsor meeting + governance involvement |
| Passive user | Ignorance + Fear | Low | Targeted communication + peer champion |
| Skeptical expert | Disagreement | Medium | Involve in the design + value the expertise |
| Exhausted manager | Saturation | Medium | Lighten load, sequence, recognize effort |

## Action plan — Resistance management

```
STEP 1 — LISTEN BEFORE ACTING
  Run individual interviews (30 min, confidential)
  Key questions:
  - "What worries you about this project?"
  - "What would help you move forward?"
  - "What should be different?"

STEP 2 — QUALIFY THE RESISTANCE
  Type? Influence level? Risk to the project?
  → Prioritize the high-impact resisters

STEP 3 — TARGETED ACTION PLAN
  Per profile: communication / coaching / involvement / negotiation

STEP 4 — TURN INTO AN AMBASSADOR
  Publicly value the change of stance
  Give them an internal champion role
```

## Facilitation techniques

```
TECHNIQUE 1 — Active listening (Carl Rogers)
  Reformulate, validate the emotion, don't counter-argue upfront
  "I hear that you're worried about... that's legitimate."

TECHNIQUE 2 — Socratic questioning
  Open questions to surface the solution
  "What would need to happen for you to be comfortable?"

TECHNIQUE 3 — Involve the resister in the solution
  "Your expertise is valuable — how would we do better in your view?"
  → Turn opposition into contribution

TECHNIQUE 4 — Visible quick wins
  Quickly show concrete results to reduce doubts
  → Pick enthusiastic pilots as the first ambassadors
```

## Deliverables
- Resistance register (type, profile, strategy)
- Diagnosis interview plan
- Targeted action plan per profile
- Tracking of resistance evolution

## Output format
Specify: nature of the change, profiles identified as resistant, influence level, organizational context.
