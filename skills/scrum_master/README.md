## Choosing the right skill — Decision tree

```
You want to ...

  ... FACILITATE A SCRUM EVENT?
    → facilitation-ceremonies (overview + agendas Planning/Daily/Review/Retro/Refinement)
    → retrospective-avancee (varied formats: Sailboat, Fishbone, Timeline, Prime Directive)
    → planning-poker (collective Fibonacci estimation, alternatives, remote)

  ... COACH THE TEAM OR THE PO?
    → coaching-equipe / coaching-po-sm
    → conflict-resolution (if tensions)

  ... STEER THE QUALITY OF THE AGILE SYSTEM?
    → gestion-impediments / metriques-agiles
    → amelioration-continue (continuous Kaizen)

  ... SCALE (SAFe)?
    → scaling-safe-ssm (SSM role in the ART)
    → community-of-practice (cross-cutting CoPs)

  ... DRIVE A TRANSFORMATION?
    → change-management-agile (Kotter + ADKAR)
    → onboarding-agile (new team)
```
