## Choosing the right skill — Decision tree

```
You want to ...

  ... UNDERSTAND THE USERS?
    → user-research.md (interviews + observations)
    → personas-jtbd.md (personas + Jobs To Be Done)
    → journey-mapping.md (journeys)
    → benchmark-concurrent.md (state of the market)

  ... DESIGN THE EXPERIENCE?
    → architecture-information.md (structure)
    → wireframing.md (first mockups)
    → prototypage-figma.md (interactivity)
    → design-system.md (consistency)

  ... DESIGN WITH AI?
    → design-for-ai.md (chat UI, voice UI, prompts)

  ... VALIDATE THE DESIGN?
    → tests-utilisateurs.md (qualitative)
    → ab-testing.md (quantitative)
    → audit-ux-heuristiques.md (expert review)
    → accessibilite-wcag.md (RGAA/WCAG compliance)
    → metriques-ux.md (SUS / HEART / NPS)

  ... WORK WITH THE TEAM?
    → design-handoff.md (to the devs)
    → design-agile-safe.md (sprint integration)
    → facilitation-ateliers.md (Design Sprint, Co-design)
    → storytelling-stakeholders.md (present to the leadership team)
```
