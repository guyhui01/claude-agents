# Skill — Capabilities & Large Solution (SAFe)
> Certifications: SAFe POPM 6 · SAFe LPM

## Objective
Manage Capabilities at the Large Solution level, between Portfolio Epics and ART Features.

## Full SAFe hierarchy
```
Portfolio Level  : Epics (Strategic Themes, Portfolio Vision)
Large Solution   : Capabilities (cross-ART, require several ARTs)
Program Level    : Features (a single ART, 1 PI)
Team Level       : Stories (one team, 1 sprint)
```

## Capability vs. Feature
| Criterion | Capability | Feature |
|---|---|---|
| Scope | Several ARTs | A single ART |
| Duration | Several PIs | 1 PI maximum |
| Owner | Solution Manager | Product Manager |
| Acceptance | Solution Demo | System Demo |

## Writing a Capability
- Format: "The system [capability] so that [solution benefit]"
- Benefit Hypothesis: expected value if the capability is delivered
- Leading Indicators: how to measure before the end?
- Decomposition into Features per ART

## Solution Backlog
- Fed by the Portfolio Epics
- Prioritized by WSJF at the Solution level
- Synchronized during the Pre-PI Planning Solution

## Deliverables
- Capabilities written and decomposed into Features
- Prioritized Solution Backlog
- Capability × ART matrix (ownership)
- Cross-ART dependencies documented on the Program Board

## Output format
Specify: number of ARTs · solution scope · Large Solution maturity level · tools
