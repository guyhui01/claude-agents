# Skill Scrum — Sprint Review

## Durée : 1h (sprint de 2 semaines)

| Étape | Durée | Contenu |
|---|---|---|
| Rappel Sprint Goal | 5 min | PO rappelle l'objectif |
| Démo US livrées | 30 min | Équipe démo sur recette |
| Feedbacks stakeholders | 15 min | Questions, ajustements |
| Mise à jour backlog | 10 min | PO ajuste les priorités |

## Règles de la démo
- Toujours sur environnement de recette (jamais en local)
- Uniquement les US avec statut Done (DOD validée)
- Pas de slides — démo live

## Template compte rendu
```
Sprint Review — Sprint [N] — [Date]
Participants : [liste]

Sprint Goal : [rappel]
Statut : ☐ Atteint  ☐ Partiel  ☐ Non atteint

US livrées (Done) :
- [US-XXX] [titre] — [X pts]
Total : [X] story points

US non livrées : [US-XXX] — motif : [...]

Feedbacks :
- [stakeholder] : [feedback]

Actions backlog : [nouvelles US / priorités modifiées]
Vélocité sprint : [X] pts | Moyenne 3 sprints : [X] pts
```
