# Skill — Synthèse Exécutive (Executive Summary)
> Certifications : HubSpot Content Marketing · Copyblogger Certified Content Marketer · McKinsey Writing Program

## Objectif
Rédiger des synthèses exécutives percutantes qui permettent aux décideurs de comprendre l'essentiel en 2-3 minutes et de prendre une décision éclairée.

## Principe fondateur : la pyramide de Minto *(Barbara Minto, 1987)*
```
RÉPONSE DIRECTE D'ABORD
    ↓
Arguments / Preuves (groupés par thème)
    ↓
Données détaillées (en support)

Règle : Dire la conclusion en PREMIER, puis justifier
❌ "Après avoir analysé 6 mois de données, examiné 12 indicateurs,
     consulté 4 équipes et lu 3 études de marché, nous pensons que..."
✅ "Nous recommandons de lancer le projet X. Voici pourquoi."
```

## Structure en 4 blocs (SCQ + R)

### Situation — Complication — Question — Résolution
```
SITUATION   : Ce que tout le monde sait (contexte partagé)
              → Factuel, neutre, 2-3 phrases max
              Exemple : "Notre taux de churn est de 4,2% (T1 2026),
                          contre 2,8% pour nos concurrents principaux."

COMPLICATION: Ce qui change / ce qui pose problème
              → Le "mais" qui crée l'urgence
              Exemple : "Sans action, ce taux atteindra 6% d'ici Q4
                          selon les projections actuelles, soit une perte
                          de 2,3M€ de revenus récurrents."

QUESTION    : La question implicite du lecteur
              → Souvent non écrite, mais structurante
              Exemple : "Que doit-on faire pour endiguer ce churn ?"

RÉSOLUTION  : Votre réponse directe
              → Recommandation claire + plan d'action
              Exemple : "Lancer un programme de rétention en 3 phases
                          ciblant les segments Gold et Silver prioritaires."
```

## Template de synthèse exécutive (1 page)
```markdown
# [Titre du document]
**Date** : [Date] | **Auteur** : [Nom] | **Pour** : [Destinataire(s)]

---

## En bref
[2-3 phrases maximum résumant l'enjeu et la recommandation principale]

## Contexte
[1 paragraphe : situation actuelle, données clés, enjeu business]

## Problème identifié
[1 paragraphe : ce qui ne va pas, impact chiffré si possible]

## Recommandation
> **[Action principale recommandée]**

[Justification en 3-4 points clés :]
- **[Point 1]** : [Argument + donnée]
- **[Point 2]** : [Argument + donnée]
- **[Point 3]** : [Argument + donnée]

## Prochaines étapes
| Action | Responsable | Échéance |
|--------|-------------|----------|
| [Action 1] | [Qui] | [Quand] |
| [Action 2] | [Qui] | [Quand] |

**Décision demandée** : [Ce que vous attendez du lecteur — validation, budget, ressources]
```

## Règles d'or de la synthèse exécutive

### Ce qu'il faut faire
```
✅ Commencer par la conclusion (pas par l'historique)
✅ Une seule idée par phrase
✅ Chiffrer chaque affirmation ("significatif" → "23%")
✅ Langage business, pas technique
✅ Proposer UNE décision à prendre (pas plusieurs options)
✅ Lier chaque constat à un impact business (€, %, clients)
✅ Relire en se demandant "et alors ?" après chaque phrase
```

### Ce qu'il faut éviter
```
❌ Commencer par "Dans le cadre de..." ou "Suite à..."
❌ Répéter le contenu du rapport en miniature
❌ Jargon non maîtrisé par le lecteur cible
❌ Conditionnel qui dilue la recommandation ("il faudrait peut-être")
❌ Plus de 500 mots (une vraie synthèse = 1 page max)
❌ Tableaux complexes (max 1 tableau simple)
❌ Acronymes non explicités
```

## Formulations impactantes

### Amorces de recommandation
```
"Nous recommandons [action] afin de [bénéfice mesurable]."
"La priorité est de [action] d'ici [date] pour [raison]."
"Pour atteindre [objectif], la décision à prendre est [action]."
```

### Tournures à éviter → remplacements
```
"Il convient de noter que..."  → Supprimer ou reformuler directement
"Dans un premier temps..."     → "D'abord, / Premièrement,"
"Au niveau de..."              → "Sur / Concernant / Pour"
"Suite à l'analyse..."        → Aller directement au résultat
"Il semblerait que..."        → Affirmer ou citer la source
"Relativement important"      → Donner le chiffre exact
```

## Adaptation par audience
```
CODIR (5 min de lecture max)
  → 1 page, langage business, focus ROI et risque
  → Section "décision demandée" obligatoire

CONSEIL D'ADMINISTRATION
  → 1/2 page, chiffres clés en gras, impact réglementaire si pertinent
  → Aucune hypothèse non validée

CLIENT EXTERNE
  → Ton valorisant et positif
  → Mettre en avant les bénéfices pour le client, pas pour nous
  → Éviter toute information confidentielle

INVESTISSEUR / BANQUIER
  → Focus : rentabilité, scalabilité, risques maîtrisés
  → Projections financières avec hypothèses explicites
```

## Livrables
- Synthèse exécutive (1 page A4 / format slide)
- Version ultra-courte pour email (5 lignes max)
- Présentation "pitch" de 5 min associée si nécessaire

## Format de sortie
Précise : sujet du document source · décideur cible · décision attendue · contrainte de longueur · ton souhaité (assertif, consultatif, neutre)
