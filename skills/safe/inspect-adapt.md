# Skill SAFe — Inspect & Adapt

## Structure (4h en fin de PI)
| Étape | Durée | Description |
|---|---|---|
| PI System Demo | 1h | Démo de l'incrément complet du PI |
| Quantitative Measurement | 30 min | Analyse des métriques PI |
| Problem Solving Workshop | 2h | Identification et résolution |
| Présentation des actions | 30 min | Engagement sur le plan d'amélioration |

## Métriques PI à analyser
- Predictability : BV réelle / BV planifiée (cible 80-100%)
- Vélocité par équipe et par train
- Qualité : bugs, dette technique accumulée
- Satisfaction équipes (vote de confiance)

## Problem Solving Workshop
```
Étape 1 : Identifier le problème racine (5 Whys / Fishbone)
Étape 2 : Brainstorming solutions
Étape 3 : Sélectionner les solutions (vote par points)
Étape 4 : Plan d'actions SMART
Étape 5 : Présentation et engagement de l'équipe
```

## Template rapport I&A
```

   Action : [action SMART] — Responsable : [prénom] — Délai : [date]

Engagement équipe : [vote de confiance moyen : X/5]
```
