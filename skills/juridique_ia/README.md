## Choosing the right skill — Decision tree

```
You want to ...

  ... ASSESS AN AI PROJECT'S COMPLIANCE?
    → ai-act-conformite.md (AI Act risk classification)
    → rgpd-ia.md (legal bases, rights)
    → dpia-systemes-ia.md (data-subject impact)
    → audit-conformite-ia.md (full audit)

  ... CONTRACT?
    → contrats-ia.md (AI clauses, IP, SLA)
    → propriete-intellectuelle-ia.md (models, datasets)

  ... GOVERN AI IN THE ENTERPRISE?
    → politique-ia-entreprise.md (internal charter)
    → gouvernance-ethique-ia.md (ethics committee, fairness)
    → veille-reglementaire.md (tracking developments)

  ... SECTOR-SPECIFIC CYBER COMPLIANCE?
    → nis2-conformite.md (essential/important entities)
```
