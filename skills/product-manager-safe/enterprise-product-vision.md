# Skill — Enterprise Product Vision

> Certification: PSPO III · SAFe LPM · SAFe POPM 6 · SAFe SPC
> Agent: AGENT-PRODUCT-MANAGER-SAFE.md

## Objective
Define, communicate and align an ambitious and inspiring product vision across the enterprise, connecting the business strategy to day-to-day product decisions.

## Product vision levels

```
ENTERPRISE VISION (3-5 years)
"Why we exist — impact on the world"
        │
PRODUCT VISION (1-3 years)
"What our product will become — user promise"
        │
STRATEGIC ROADMAP (6-18 months)
"The major steps toward the vision"
        │
PI / QUARTERLY ROADMAP (3 months)
"What we deliver this quarter"
        │
BACKLOG / SPRINT
"What we do this week"
```

## North Star Metric

The single metric that captures the value created for users:
```
North Star = [Metric] that reflects [user value]
            measured [frequency] via [method]

Examples:
- Spotify: "Minutes listened / user / month"
- Airbnb: "Nights booked"
- LinkedIn: "Connections creating professional opportunities"
- B2B product: "Orders placed in < 5 minutes"
```

## Product Strategy Canvas

| Dimension | Key questions |
|---|---|
| **Market** | Which segment to target first? Why? |
| **Problem** | Which problem do we solve better than anyone? |
| **Differentiation** | Why us rather than a competitor? |
| **Value model** | How do we create and capture value? |
| **Growth** | How do we acquire and retain users? |

## Communicating the vision (C-Level)

### Executive format (10 slides max)
1. **Market context** — trends and opportunity
2. **User problem** — pain point validated by data
3. **Our vision** — an ambitious yet inspiring future state
4. **Positioning** — differentiation vs alternatives
5. **Roadmap** — Now / Next / Later (no fixed dates)
6. **OKRs** — 3 objectives + success metrics
7. **Investment required** — team, budget, timeline
8. **Risks and mitigation** — 3 key risks
9. **Quick wins** — what we deliver in 90 days
10. **Call to action** — decision expected

### Vision storytelling ("From → To" format)
```
TODAY (current situation — frustration)
"Today, our B2B customers spend 45 minutes ordering
 on our portal, with 30% data-entry errors..."

TOMORROW (vision — desire)
"Tomorrow, Thomas places an order in 3 minutes from his
 construction site, with instant confirmation and real-time tracking."

THE GAP (our role)
"We are the only IT services firm able to deliver this experience
 on Drupal Commerce with the existing ERP integration."
```

## Vision → Backlog alignment

```
Vision ──► OKR ──► Epic ──► Feature ──► User Story ──► Task
  "Why"        "What"  "How"       "Detail"    "Action"    "Work"
```

Every US must be able to trace back up to the vision in 4 steps maximum.
