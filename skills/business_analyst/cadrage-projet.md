# Skill — Cadrage de Projet
> Certifications : PMI-PBA · IIBA CBAP · TOGAF 10

## Objectif
Définir le périmètre, les enjeux et les conditions de succès d'un projet avant son lancement.

## Note de cadrage — Structure type
```
1. Contexte et enjeux
   - Situation actuelle et problématique
   - Objectifs stratégiques associés
2. Périmètre
   - In scope : ce qui est inclus
   - Out of scope : ce qui est explicitement exclu
3. Parties prenantes
   - Commanditaire / Sponsor
   - MOA, MOE, utilisateurs
   - RACI simplifié
4. Livrables attendus
   - Liste des livrables avec critères de succès
5. Planning macro
   - Jalons clés (phases, Go/No-go)
6. Budget estimatif
   - Enveloppe, postes de coût principaux
7. Risques et hypothèses
   - Top 5 risques + mitigation
   - Hypothèses de travail
8. Conditions de succès
   - KPIs de succès du projet
9. Décision demandée
   - Validation de lancement / arbitrage
```

## Étude de faisabilité
| Dimension | Questions clés |
|---|---|
| **Technique** | La solution est-elle techniquement réalisable ? |
| **Organisationnelle** | L'organisation peut-elle absorber le changement ? |
| **Financière** | Le ROI est-il positif ? Le budget est-il disponible ? |
| **Juridique** | Y a-t-il des contraintes réglementaires ? (RGPD, AI Act) |
| **Temporelle** | Le délai est-il réaliste ? |

## Matrice Eisenhower pour le périmètre
```
Important + Urgent   → Phase 1 (MVP)
Important + Non urgent → Phase 2
Non important + Urgent → À déprioriser ou déléguer
Non important + Non urgent → Out of scope
```

## Livrables
- Note de cadrage validée par le sponsor
- Étude de faisabilité (si nécessaire)
- Périmètre documenté (in/out scope)
- Planning macro avec jalons

## Format de sortie
Précise : type de projet (IA, SI, transformation) · contexte client · contraintes connues · décision attendue
