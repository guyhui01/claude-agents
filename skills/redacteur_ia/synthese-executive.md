# Skill — Executive Summary
> Certifications: HubSpot Content Marketing · Copyblogger Certified Content Marketer · McKinsey Writing Program

## Objective
Write punchy executive summaries that let decision-makers grasp the essentials in 2-3 minutes and make an informed decision.

## Founding principle: the Minto pyramid *(Barbara Minto, 1987)*
```
DIRECT ANSWER FIRST
    ↓
Arguments / Evidence (grouped by theme)
    ↓
Detailed data (in support)

Rule: State the conclusion FIRST, then justify
❌ "After analyzing 6 months of data, reviewing 12 indicators,
     consulting 4 teams and reading 3 market studies, we think that..."
✅ "We recommend launching project X. Here's why."
```

## 4-block structure (SCQ + R)

### Situation — Complication — Question — Resolution
```
SITUATION   : What everyone knows (shared context)
              → Factual, neutral, 2-3 sentences max
              Example: "Our churn rate is 4.2% (Q1 2026),
                          vs 2.8% for our main competitors."

COMPLICATION: What changes / what's the problem
              → The "but" that creates urgency
              Example: "Without action, this rate will hit 6% by Q4
                          per current projections, i.e. a loss
                          of €2.3M in recurring revenue."

QUESTION    : The reader's implicit question
              → Often unwritten, but structuring
              Example: "What should we do to stem this churn?"

RESOLUTION  : Your direct answer
              → Clear recommendation + action plan
              Example: "Launch a 3-phase retention program
                          targeting the priority Gold and Silver segments."
```

## Executive summary template (1 page)
```markdown
# [Document title]
**Date**: [Date] | **Author**: [Name] | **For**: [Recipient(s)]

---

## In brief
[2-3 sentences max summarizing the issue and the main recommendation]

## Context
[1 paragraph: current situation, key data, business stake]

## Identified problem
[1 paragraph: what's wrong, quantified impact if possible]

## Recommendation
> **[Main recommended action]**

[Justification in 3-4 key points:]
- **[Point 1]**: [Argument + data]
- **[Point 2]**: [Argument + data]
- **[Point 3]**: [Argument + data]

## Next steps
| Action | Owner | Deadline |
|--------|-------------|----------|
| [Action 1] | [Who] | [When] |
| [Action 2] | [Who] | [When] |

**Decision requested**: [What you expect from the reader — approval, budget, resources]
```

## Golden rules of the executive summary

### What to do
```
✅ Start with the conclusion (not the backstory)
✅ One idea per sentence
✅ Quantify every claim ("significant" → "23%")
✅ Business language, not technical
✅ Offer ONE decision to make (not several options)
✅ Tie every finding to a business impact (€, %, clients)
✅ Re-read asking "so what?" after each sentence
```

### What to avoid
```
❌ Starting with "As part of..." or "Following..."
❌ Repeating the report's content in miniature
❌ Jargon the target reader doesn't master
❌ Conditional wording that dilutes the recommendation ("we might perhaps")
❌ More than 500 words (a real summary = 1 page max)
❌ Complex tables (max 1 simple table)
❌ Unexplained acronyms
```

## Impactful phrasings

### Recommendation openers
```
"We recommend [action] in order to [measurable benefit]."
"The priority is to [action] by [date] to [reason]."
"To reach [objective], the decision to make is [action]."
```

### Phrasings to avoid → replacements
```
"It should be noted that..."  → Delete or rephrase directly
"As a first step..."          → "First,"
"At the level of..."          → "On / Regarding / For"
"Following the analysis..."   → Go straight to the result
"It would seem that..."       → Assert or cite the source
"Relatively significant"      → Give the exact number
```

## Adaptation by audience
```
EXEC COMMITTEE (5 min read max)
  → 1 page, business language, focus on ROI and risk
  → "Decision requested" section mandatory

BOARD OF DIRECTORS
  → 1/2 page, key figures in bold, regulatory impact if relevant
  → No unvalidated assumption

EXTERNAL CLIENT
  → Flattering, positive tone
  → Highlight benefits for the client, not for us
  → Avoid any confidential information

INVESTOR / BANKER
  → Focus: profitability, scalability, controlled risks
  → Financial projections with explicit assumptions
```

## Deliverables
- Executive summary (1 A4 page / slide format)
- Ultra-short version for email (5 lines max)
- Associated 5-min "pitch" presentation if needed

## Output format
Specify: source document topic · target decision-maker · expected decision · length constraint · desired tone (assertive, consultative, neutral)
