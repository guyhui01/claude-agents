# Skill — Reporting MOA (COPIL, Tableaux de bord)
> Certifications : IIBA CBAP · PMI-PBA

## Objectif
Produire des reportings clairs et actionnables pour les comités de pilotage et les parties prenantes du projet.

## Types de reportings MOA
| Format | Fréquence | Public | Durée |
|---|---|---|---|
| **Point hebdomadaire** | Hebdo | Équipe projet | 5-10 min |
| **Rapport d'avancement** | Bimensuel | Chef de projet, MOE | 1 page |
| **Tableau de bord COPIL** | Mensuel | Sponsors, Direction | 5-10 slides |
| **Bilan de phase** | Fin de phase | Comité de steering | 15 min |

## Tableau de bord COPIL — Structure
```
1. Synthèse exécutive (1 slide)
   - Indicateur global : 🟢 Vert / 🟡 Orange / 🔴 Rouge
   - 3 points clés de la période

2. Avancement du planning (1 slide)
   - Jalons réalisés vs. prévus
   - Jalons à venir (M+1, M+2)
   - Tendance (en avance, dans les temps, en retard)

3. Budget (1 slide)
   - Consommé vs. budgeté
   - Reste à faire (RAF)
   - Projection de fin de projet

4. Risques et points d'attention (1 slide)
   - Top 3 risques actifs (probabilité × impact)
   - Actions de mitigation en cours

5. Décisions demandées (1 slide)
   - Points nécessitant arbitrage du COPIL
   - Options proposées avec recommandation
```

## Indicateurs clés MOA
- **Taux de couverture des exigences** : % exigences testées
- **Taux de réussite recette** : % cas de test OK
- **Anomalies bloquantes ouvertes** : nombre
- **Taux d'avancement** : % livrables validés vs. prévus
- **Satisfaction utilisateurs** : score 1-5 post-ateliers

## Code couleur RAG (Red-Amber-Green)
- 🟢 **Vert** : dans les temps, dans le budget, aucun risque majeur
- 🟡 **Orange** : léger retard ou dépassement, risque identifié sous contrôle
- 🔴 **Rouge** : retard significatif ou dépassement, risque majeur, action requise

## Livrables
- Template tableau de bord COPIL (PowerPoint / Notion)
- Rapport d'avancement hebdomadaire
- Dashboard indicateurs (Excel / Power BI / Confluence)

## Format de sortie
Précise : type de reporting · fréquence · public · indicateurs disponibles · outil de présentation
