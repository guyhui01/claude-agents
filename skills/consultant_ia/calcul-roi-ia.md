# Skill — Calcul ROI d'un Projet IA
> Certifications : CAP IABAC · AI+ Business · PMI-ACP

## Objectif
Construire un business case IA solide avec un calcul de ROI crédible pour convaincre les décideurs.

## Structure du Business Case IA

### 1. Investissements (coûts)
| Poste | Description | Montant estimé |
|---|---|---|
| Développement | PoC, développement, intégration | X € |
| Infrastructure | Cloud, GPU, licences | X €/an |
| Données | Collecte, nettoyage, labellisation | X € |
| Change management | Formation, accompagnement | X € |
| Maintenance | MCO, évolutions | X €/an |
| **Total TCO 3 ans** | | **X €** |

### 2. Bénéfices (gains)
| Type | Indicateur | Valeur annuelle |
|---|---|---|
| **Gains directs** | Réduction coûts opérationnels | X € |
| | Automatisation tâches manuelles | X jours/an × TJM |
| | Réduction erreurs / retraitements | X € |
| **Gains indirects** | Amélioration satisfaction client | X% → impact CA |
| | Accélération time-to-market | X semaines gagnées |
| | Réduction churn | X% → X € CA préservé |

## Formules clés
```
ROI = (Gains totaux - Investissements) / Investissements × 100

Délai de retour (payback) = Investissements / Gains annuels nets

VAN (NPV) = Σ (Flux annuels / (1+taux)^année) - Investissement initial
```

## Méthode de calcul en 5 étapes
1. **Identifier le cas d'usage** : périmètre précis, volume traité, fréquence
2. **Quantifier l'état actuel** : coût/temps actuel (baseline)
3. **Estimer l'amélioration IA** : % d'automatisation, réduction d'erreurs
4. **Projeter sur 3 ans** : courbe de montée en charge réaliste
5. **Calculer ROI, VAN, payback** avec scénarios (pessimiste / réaliste / optimiste)

## Benchmarks ROI IA 2026
| Use case | ROI typique | Payback |
|---|---|---|
| Chatbot service client | 200-400% | 6-12 mois |
| Automatisation RPA + IA | 300-600% | 4-8 mois |
| Prédiction churn | 150-300% | 12-18 mois |
| Génération de contenu IA | 400-800% | 3-6 mois |
| Vision par ordinateur QC | 100-250% | 18-24 mois |

## Livrables
- Business case complet (Excel / Google Sheets)
- Synthèse ROI 1 page (pour CODIR)
- Scénarios pessimiste / réaliste / optimiste
- Hypothèses documentées et validées

## Format de sortie
Précise : cas d'usage · volume actuel · coût actuel · % d'automatisation cible · horizon d'évaluation (1/3/5 ans)
