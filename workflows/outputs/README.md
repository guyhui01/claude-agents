# Outputs — Raw workflow results

> This folder holds the outputs generated during the live execution of the workflows from the briefs.
> Traceable but not curated — an intermediate between brief and use case.

---

## Pipeline

```
briefs/ → [run workflow] → outputs/ → [curation] → use_cases/
```

---

## Governance

| Criterion | Rule |
|---------|-------|
| Editable | ✅ Yes — post-run enrichment possible |
| Committed | ✅ Always — traceability mandatory |
| Promoted to use_case | If the output is judged showcase-quality |

---

## Naming convention

```
WF-{ID}-output-{sector}-{context}.md
```

Link with the source brief:
```
briefs/    WF-002-brief-assurance-pi01.md   ← input
outputs/   WF-002-output-assurance-pi01.md  ← result
use_cases/ WF-002-uc01-assurance-pi01.md    ← if promoted
```
