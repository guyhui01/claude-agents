## Choosing the right skill — Decision tree

```
You want to ...

  ... START AN AI PROJECT?
    → cadrage-projet-ia.md (charter + WBS + success criteria)
    → gestion-risques-projet.md (matrix + AI Act from day 1)
    → stakeholder-management.md (mapping)

  ... PLAN / TRACK?
    → planification-hybride.md (Agile + Waterfall)
    → evm-valeur-acquise.md (EVM if project > 6 months)
    → reporting-codir.md (monthly status)

  ... MANAGE A PORTFOLIO?
    → gouvernance-portefeuille.md (multi-project)

  ... CLOSE OUT OR CAPTURE LESSONS LEARNED?
    → post-mortem-rex.md (blameless + action plan)
```
