# Skill — Customer Discovery & Lean Startup
> Certifications : PSPO II · PSPO III · ICAgile ICP-APO

## Objectif
Valider les hypothèses produit auprès de vrais clients avant de construire, pour réduire le risque d'échec.

## Cycle Build-Measure-Learn
```
Idée → Build (MVP) → Mesure → Learn → Pivot ou Persévère
```

## Types d'hypothèses à tester
- **Hypothèse de valeur** : ce problème vaut la peine d'être résolu
- **Hypothèse de viabilité** : les clients paieront pour cette solution
- **Hypothèse de faisabilité** : nous pouvons le construire

## Techniques de discovery
| Technique | Durée | Output |
|---|---|---|
| Customer Interview (PSPO) | 30-45 min | Insights qualitatifs |
| Fake Door Test | 1 semaine | Taux d'intérêt mesuré |
| Landing Page MVP | 2 jours | Conversion / liste d'attente |
| Concierge MVP | 1 sprint | Validation manuelle du service |
| Smoke Test | 48h | Validation intention d'achat |

## Structure d'une interview de discovery
1. Contexte (ne pas mentionner la solution)
2. Problème actuel : "Comment faites-vous aujourd'hui ?"
3. Douleur : "Qu'est-ce qui est frustrant ?"
4. Tentatives : "Qu'avez-vous essayé ?"
5. Rêve : "Quelle serait la solution idéale ?"

## Livrables
- Hypothèses priorisées (riskiest assumption first)
- Guide d'interview customer
- Synthèse des insights (Opportunity Solution Tree)
- Go / No-go par hypothèse testée

## Format de sortie
Précise : stade du produit · hypothèse à tester · public cible · délai · ressources disponibles
