```
  ... CLÔTURER OU RETOURNER D'EXPÉRIENCE ?

```

## Référentiels et standards utilisés

- **PMBOK 7** (PMI) : performance domains, principles, tailoring
- **PRINCE2** : 7 principes, 7 thèmes, 7 processus
- **PMI-ACP / DASM** : pour hybride Agile-Waterfall
- **SAFe LPM** : pour portefeuille
- **EVM** (PMI standard) : Earned Value Management
- **PROSCI ADKAR** : pour stakeholders et change
- **MoP** (Management of Portfolios — Axelos) : gouvernance portefeuille
