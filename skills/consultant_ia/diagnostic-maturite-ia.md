# Skill — Diagnostic de Maturité IA
> Certifications : CAP IABAC · Google Cloud Digital Leader · Azure AI-900

## Objectif
Évaluer le niveau de maturité IA d'une organisation pour définir les priorités d'investissement et la feuille de route.

## Modèle de maturité IA — 5 niveaux
| Niveau | Nom | Description |
|---|---|---|
| 1 | **Initial** | Expérimentations isolées, pas de stratégie |
| 2 | **Exploratoire** | PoCs en cours, équipe data naissante |
| 3 | **Défini** | Projets IA en production, gouvernance en place |
| 4 | **Géré** | IA mesurée, ROI démontré, scalabilité |
| 5 | **Optimisé** | IA intégrée à la stratégie, amélioration continue |

## Grille d'évaluation — 6 dimensions
| Dimension | Indicateurs évalués | Score /5 |
|---|---|---|
| **Stratégie & Vision** | Ambition IA, alignement direction, budget dédié | |
| **Data & Infrastructure** | Qualité des données, cloud, DataOps | |
| **Compétences & Talents** | Data scientists, ML engineers, culture data | |
| **Gouvernance & Éthique** | Comité IA, AI Act, RGPD, responsabilité | |
| **Cas d'usage & Valeur** | Nombre de projets, ROI mesuré, adoption | |
| **Technologie & Outillage** | MLOps, LLMOps, plateformes IA | |

## Méthode de diagnostic
1. **Interviews** : DSI, CDO, DG, métiers (30-45 min chacun)
2. **Questionnaire auto-évaluation** : diffusé aux équipes data/IA
3. **Revue documentaire** : stratégie SI, organigramme, projets en cours
4. **Démo de l'existant** : si des outils IA sont déjà déployés

## Livrables du diagnostic
- Radar de maturité IA (6 dimensions)
- Rapport de diagnostic (forces, faiblesses, opportunités)
- Benchmark sectoriel (niveau moyen du secteur)
- Quick wins identifiés (valeur rapide en < 3 mois)
- Recommandations pour la feuille de route

## Format de sortie
Précise : secteur client · taille (PME, ETI, grand groupe) · budget d'étude · délai de rendu
